# Discord — Digital Parasite (Rounded)

A Discord theme based on [system24](https://github.com/refact0r/system24) by refact0r, recolored
with the Digital Parasite palette — **rounded variant**.

## Installation

1. Install [Vencord](https://vencord.dev/) or [BetterDiscord](https://betterdiscord.app/).
2. Copy `system24-digital-parasite-rounded.theme.css` into your themes folder:
   - Vencord: `%APPDATA%/Vencord/themes/`
   - BetterDiscord: `%APPDATA%/BetterDiscord/themes/`
3. Enable the theme in Discord settings.

## Files

| File | Description |
| --- | --- |
| `system24-digital-parasite-rounded.theme.css` | Rounded theme (rounded panels and profile pictures) |
| `system24-digital-parasite.theme.css` | Square variant (kept for reference) |
| `digital-parasite.css` | Legacy CSS (kept for reference) |

## Notes

- Rounded corners: `--unrounding: off` and `--round-pfp: on`.
- Based on system24 by refact0r.
