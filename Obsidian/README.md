# Obsidian — Digital Parasite (Cyberpunk Rounded)

An [Obsidian](https://obsidian.md/) theme based on [Cyberpunk](https://github.com/nxxxsooo/obsidian-cyberpunk-theme) by nxxxsooo, recolored with the Digital Parasite palette — **rounded variant**.

## Installation

1. Copy the `Cyberpunk-Rounded` folder into your vault's `.obsidian/themes/` directory.
2. Open Obsidian → **Settings → Appearance → Themes**.
3. Select **Cyberpunk Rounded** from the theme dropdown.
4. Set the accent color to rose in **Settings → Appearance → Accent color**.

## Files

| Folder | Description |
| --- | --- |
| `Cyberpunk-Rounded/` | Rounded variant (radius 6 / 10 / 14 / 20 px) — active in both vaults |
| `Cyberpunk/` | Square variant (kept for reference) |

## Features

- Neon glow on headings (cyan, pink, green, yellow)
- H1 flicker animation (neon sign effect)
- Cyberpunk grid background
- Glitch effects and scanlines
- Rainbow horizontal rules
- Full coverage: callouts, tables, checkboxes, graph view, nav, command palette, tags
- Live preview + reading view support
- Rounded corners matching the Digital Parasite rounded theme

## Notes

- Based on the Cyberpunk theme by nxxxsooo (port of channingwalton's Typora Cyberpunk theme).
- Recolored with Digital Parasite palette. Original theme uses cyan/magenta; this version uses rose/green/cyan/yellow.
- The theme is dark-mode only.
- Radii: `--radius-s: 6px`, `--radius-m: 10px`, `--radius-l: 14px`, `--radius-xl: 20px`.
